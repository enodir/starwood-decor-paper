## 1. Индустрия: как устроено производство декоративной бумаги для ламината ДСП/МДФ

### 1.1 Что такое продукт и терминология, которую сайт должен использовать грамотно
- **Decor paper / декоративная бумага** — базовая бумага, запечатанная рисунком (гравюрная печать, ротогравюра) на бумагоделательной машине. Служит "лицом" плиты.
- **Impregnated paper / пропитанная бумага** — decor paper, пропитанная меламиновыми/карбамидными смолами для последующего прессования на ДСП/МДФ/HDF.
- **Finish foil / финиш-фольга** — гибкая пропитанная бумага с лаковым/термопластичным покрытием, разные степени блеска (глянец, матовый, супер-матовый, 3D-пора).
- **HPL (High Pressure Laminate)** — многослойный сэндвич: крафт-бумага, пропитанная фенольной смолой, + decor paper сверху + overlay, прессуется при >1000 PSI.
- **Synchro / Synchronized pore** — тиснение плиты синхронизировано с рисунком печати, имитация текстуры натурального дерева "в структуре".
- **Overlay** — защитный прозрачный слой поверх декора (износостойкость, UV-стабильность).
- **Unicolors** — однотонные пропитанные бумаги, дополняющие декоры (кромки, ЛДСП без рисунка).
- Категории дизайна: **древесные текстуры (wood grain), камень/бетон (stone/concrete), текстиль/кожа, абстракция/fantasy, металлик**.
- Субстраты-потребители: **ДСП (particleboard), МДФ/ХДФ (MDF/HDF), фанера** — использовать эти термины на сайте как факт экспертизы.

**Вывод для контента:** сайт должен свободно оперировать этой терминологией в разделе "Продукция", это сразу считывается B2B-аудиторией (закупщики, технологи мебельных и напольных производств) как признак компетентности, в отличие от текущего generic-текста в index.html.old.

### 1.2 Производственный процесс как основа для storytelling
Классическая цепочка, которую можно превратить в анимированный "путь продукта" (напрашивается как отдельная секция с scroll-driven анимацией):
1. Целлюлоза/базовая бумага → 2. Дизайн и цветоделение (студия дизайна, ротогравюрные цилиндры) → 3. Печать (ротогравюра, до 8-10 цветов) → 4. Пропитка смолами (impregnation line) → 5. Сушка → 6. Прессование на ДСП/МДФ (короткий/высокий цикл, HPL) → 7. Контроль качества → 8. Упаковка и логистика.

Это готовый нарратив "от рулона бумаги до готовой плиты" — сильный кандидат на визуальную секцию сайта (см. раздел 3.2).

### 1.3 Что обязательно есть у топ-игроков рынка (Schattdecor, Surteco/Interprint, Lamigraf, Ahlstrom)
Изучены сайты Schattdecor и Lamigraf напрямую + маркетинговые обзоры рынка.

Общая структура навигации у лидеров:
- **Decors / Коллекции** — визуальный каталог декоров (дерево, камень, унипалитра), с фильтрами по типу/цвету/финишу.
- **Products** — продуктовые линейки (decor paper, impregnated paper, finish foil, unicolors, synchro).
- **Design Hub / Trend Hub** — блог о трендах в дизайне интерьеров/мебели, часто с подпиской на рассылку трендов.
- **Sustainability** — отдельный полноценный раздел (не просто абзац): FSC/PEFC цепочка поставок, экологичность смол, углеродный след.
- **About / Company** — история, география производства, сертификаты качества.
- **Careers** — отдельный раздел (сигнал масштаба компании).
- Мультиязычность как норма (у Lamigraf 6 языков, у Schattdecor — 9+).
- B2B-функциональность: логин для партнёров/клиентов, персональный кабинет, поиск по каталогу.
- **"Find your decor" / decor finder** — интерактивный подбор декора — постоянно встречающийся CTA.
- Footer: контакты по регионам, ссылки на политику качества, "complaints channel" (канал претензий — специфично для тяжёлой индустрии).

**Вывод:** индустрия НЕ делает "маркетинговый лендинг ни о чём" — доверие строится через (а) визуальный каталог декоров как главный актив, (б) подчёркнутую техническую/производственную экспертизу, (в) устойчивое развитие как отдельный полноценный раздел, а не строчку в футере, (г) многоязычность и региональность.

## 2. Best practices для B2B / industrial сайтов в 2026

Источники: Directive Consulting, Windmill Strategy, Nopio, Pixerts, Blend B2B, Thomasnet.

### 2.1 Поведение покупателя (важно для приоритизации контента)
- До **80% research** B2B-покупатель проходит самостоятельно онлайн до первого контакта с продавцом.
- Решение "стоит ли продолжать смотреть на этого поставщика" принимается за **60-90 секунд** — hero-секция и первый экран должны сразу отвечать "кто вы, что производите, почему вам можно доверять".
- Закупщики и технологи оценивают поставщика по трём осям: **procurement-ориентированная информационная архитектура, техническая производительность сайта (Core Web Vitals, LCP < 2.5s), и наличие структурированного контента** (спецификации, сертификаты).

### 2.2 Простота важнее креативности
- Тренд 2026: **чистые, быстрые сайты вместо визуальной сложности**. B2B-покупатели ценят предсказуемость навигации выше "вау-эффекта".
- Практическое следствие для DECOSTAR: motion-дизайн должен работать НА понятность (направлять внимание, объяснять процесс), а не быть самоцелью/украшением.

### 2.3 Обязательные элементы доверия (trust signals)
- ISO-сертификаты, отраслевые ассоциации, награды за безопасность/качество.
- Клиентские кейсы / отзывы, логотипы партнёров (см. текущий блок в 1_instruction.md — это подтверждено индустрией, не выдумка).
- Явные контакты для B2B (не только форма — телефон, email отдела продаж, адреса производств).

### 2.4 Интерактивная визуализация продукта
- Для технических продуктов — 3D-модели, конфигураторы, анимированные демо вместо звонка менеджеру.
- Для decor paper это прямо соответствует **decor finder / swatch picker** — интерактивная сетка декоров с превью текстуры "как на плите", zoom по текстуре, фильтр по коллекции/цвету/финишу.

### 2.5 Чёткие пути конверсии
- На каждой странице/секции должен быть очевидный следующий шаг: "Запросить образец", "Скачать каталог/спецификацию (PDF)", "Связаться с менеджером по региону".
- CTA должны быть разного "веса" в зависимости от готовности покупателя (сравнимо с рекомендацией из 1_instruction.md про primary/secondary CTA).

## 3. Motion design: что уместно и что нет

Источники: GSAP docs/demos, Envato Elements trends 2026, Josh Comeau (scroll-driven animations), Digital Silk, Prismic.

### 3.1 Общий принцип 2026: "purposeful motion", не декоративная анимация
- Индустрия двигается от "анимация ради вау" к **motion, который объясняет** — стагеринг для иерархии информации, transitions как визуальные сигналы перехода между смысловыми блоками.
- Для тяжёлой промышленности (buyer = инженер/технолог/закупщик) — экономность важнее эффектности. Каждая анимация должна отвечать на вопрос "что она объясняет или на что указывает".

### 3.2 Конкретные паттерны, применимые к DECOSTAR
1. **Каскадное появление Hero** (уже заложено в 1_instruction.md) — заголовок, подзаголовок, CTA появляются с небольшим stagger (100-150ms delay между элементами), в сочетании с лёгким parallax на фоновом изображении текстуры бумаги/плиты.
2. **Scroll-driven "путь продукта"** — горизонтальный/вертикальный pinned-scroll блок, иллюстрирующий этапы производства (см. 1.2): бумага → печать → пропитка → прессование → готовая плита. Реализуется через `IntersectionObserver` или GSAP ScrollTrigger с пинингом секции и прогресс-баром этапов.
3. **Reveal-переходы между секциями** ("blinds"/"mask reveal") — уместны как редкий акцент (например, переход от Hero к "О заводе"), не на каждую секцию — иначе будет "шумно" и не соответствует B2B-ожиданиям простоты (см. 2.2).
4. **Hover-эффекты на карточках декоров/преимуществ** — микро-анимации (лёгкий scale/tilt, переход из grayscale в цвет для логотипов партнёров — этот паттерн прямо прописан в 1_instruction.md и подтверждён индустрией).
5. **Текстурный zoom** на карточке декора — при hover/tap увеличенный фрагмент текстуры (имитация "потрогать материал"), важно для продукта, где тактильность/визуальная фактура — главное УТП.
6. **Kinetic typography** — точечно, для крупных чисел-фактов (тонн бумаги в год, количество декоров в каталоге, лет на рынке, стран экспорта) — цифры "накручиваются" при попадании в viewport.
7. **Прогрессивный reveal длинных секций** — вместо отображения всего сразу, элементы появляются по мере скролла с небольшим fade+translateY (12-24px), длительность 400-600ms, easing ease-out — стандарт, не должен восприниматься как "тяжёлый".

### 3.3 Технические ограничения / performance
- LCP < 2.5s — значит: hero-изображение оптимизировано (WebP/AVIF, правильный `sizes`), тяжёлые библиотеки анимации (GSAP) подключать асинхронно/после первого рендера, избегать анимации, блокирующей main thread при первой загрузке.
- Уважать `prefers-reduced-motion` — обязательно для доступности (это же требование уже есть в 1_instruction.md как "Доступность").
- Скролл-эффекты должны работать через `transform`/`opacity` (GPU-composited), не через свойства, вызывающие layout/reflow.

### 3.4 Инструменты
- Лёгкий стек без фреймворка: чистый **GSAP + ScrollTrigger** (индустриальный стандарт для scroll-driven анимаций в 2026, работает в связке с обычным HTML/CSS/JS — подходит под текущий стек проекта index.html/style.css/script.js) либо нативные **CSS Scroll-Driven Animations** (`animation-timeline: view()`) для более простых reveal-эффектов без JS-библиотек, где не нужен pin/scrub сложной сцены.

## 4. Ключевые находки, которые меняют/дополняют исходное ТЗ (1_instruction.md)

Исходный промпт (1_instruction.md) даёт универсальный generic-скелет (Hero → Преимущества → Соц.доказательство → CTA/Прайс → Футер). Research показывает, что для decor paper индустрии этого мало. Нужно добавить:

1. **Секция "Продукция / Коллекции декоров"** — визуальный каталог с фильтрами (дерево/камень/унипалитра), это главный конверсионный актив у всех топ-игроков, не просто "преимущества".
2. **Секция "Производственный процесс"** — сторителлинг от сырья до готовой плиты, с scroll-driven анимацией — прямое конкурентное УТП индустриальных сайтов.
3. **Секция "Устойчивое развитие" (Sustainability)** — отдельный полноценный блок (FSC/PEFC, происхождение сырья, экологичность), а не строчка мелким шрифтом.
4. **Технические данные/сертификаты** как отдельный trust-блок (ISO, соответствие стандартам EPF/EN, лабораторный контроль) — критично для B2B-доверия (см. 2.3).
5. **Decor Finder / конфигуратор** как интерактивный элемент вместо статичной галереи — сильно повышает вовлечённость closer to purchase decision.
6. **Региональность/контакты по производствам** — если у DECOSTAR несколько площадок или экспортные рынки, это тоже должно быть отражено явно (уточнить у пользователя при формировании PRD).
7. Формы CTA — не просто "форма записи", а конкретно: **"Запросить образец"**, **"Скачать каталог (PDF)"**, **"Связаться с менеджером по региону"** — соответствует B2B buyer journey.
