## 1. Резюме проекта

**Бизнес:** DECOSTAR — завод по производству декоративной бумаги (decor paper) для последующего ламинирования ДСП и МДФ плит.
**Бренд-цвет:** `#845036` (тёплый терракотово-коричневый, отсылка к дереву/бумаге). На брендовых заливках (primary-кнопка, активный шаг процесса, CTA-секция) поверх этого цвета через `background-blend-mode: multiply` наложена текстура древесины Uludag Mese (`uludag-mese-bg.jpg`) — цвет остаётся тем же брендовым тоном, но с видимой фактурой волокна, а не плоской заливкой.
**Цель сайта:** B2B-лендинг, который за 60-90 секунд убеждает технолога/закупщика мебельного или напольного производства в компетентности завода и приводит к заявке на образец.
**Основной KPI-действие:** заявка "Запросить образец".

### Зафиксированные решения (из уточняющих вопросов)
| Вопрос | Решение |
|---|---|
| Продуктовая линейка | Только decor paper (без impregnated paper / finish foil — не усложняем) |
| Язык сайта | RU/EN/UZ (латиница) трилингв, переключатель на 3 языка в шапке и футере |
| Основной CTA | "Запросить образец" (primary), второй уровень — "Смотреть декоры" |
| Контент декоров/сертификатов | Плейсхолдеры + чёткая структура данных под будущую реальную загрузку |
| География/производство | Производство: Ташкент, Узбекистан. Экспорт: регионы Узбекистана и соседние страны. Контакты: +998 99 000 00 00, адрес производства — Ташкент |
| Технический стек | Остаёмся на текущем стеке проекта: HTML/CSS/JS + GSAP/ScrollTrigger (без фреймворка) |

## 2. Целевая аудитория

- **Технолог/инженер мебельного или напольного производства** — оценивает технические характеристики, декоры, соответствие стандартам.
- **Снабженец/закупщик** — сравнивает поставщиков, ищет прайс, сроки, условия поставки, сертификаты.
- **Собственник/директор небольшого производства** — быстро оценивает надёжность и масштаб завода по первому экрану.

Общее для всех трёх: приходят с конкретной задачей (не "просто посмотреть"), ценят скорость и ясность выше визуальных эффектов (research §2.2).

## 3. Структура сайта (Information Architecture)

### 3.0 Дизайн-система (из `research/03_design_direction.md`)

**Сигнатурный элемент — "Слоёный пресс" (The Layer Press):** визуальная метафора реального продукта (крафт-бумага → печатный декор-слой → смоляной overlay сходятся и спрессовываются в плиту). Используется ровно в трёх местах и больше нигде: hero (сборка слоёв при загрузке), секция производственного процесса (стек проходит стадии по скроллу), карточка декора (hover — приподнимается уголок, показывая слой текстуры под ним). Все остальные анимации — "тихие", не конкурируют с сигнатурой.

**Вторичное устройство — "регистрационная метка":** маленький crosshair + mono-подпись (`+ PASS 0X — …`) в левом верхнем углу каждой секции вместо generic eyebrow-заголовков — отсылка к меткам совмещения цвета в ротогравюрной печати.

**Палитра:**
| Токен | HEX | Роль |
|---|---|---|
| `--press-black` | `#1E1A17` | Тёмный фон (hero, процесс, футер) |
| `--kraft-brown` | `#845036` | Бренд-акцент (CTA, брендовые блоки) — задан брифом. На заливках (не на тексте/иконках) поверх цвета через `multiply` показывается текстура Uludag Mese — см. §3.9 |
| `--raw-pulp` | `#E8E4DC` | Светлый фон контентных секций (не кремовый!) |
| `--registration-cyan` | `#1C8CA0` | Рабочий акцент: интерактивные состояния, метки |
| `--ink-grey` | `#4A433C` | Текст на светлом фоне |
| `--pulp-white` | `#F7F5F1` | Поверхности карточек поверх raw-pulp |

**Типографика:** Display — PT Sans Narrow (узкий индустриальный гротеск ParaType, поддерживает кириллицу — заменил изначально рассмотренный Big Shoulders, у которого нет кириллических глифов); Body — IBM Plex Sans; Utility/mono (коды декоров, номера стадий, метки) — IBM Plex Mono. Сознательно не используем контрастный serif-дисплей на кремовом фоне (AI-дефолт клише №1). Шрифты самохостятся (WOFF2, только cyrillic+latin subset) с `font-display: swap`.

**Футер как колофон:** см. §3.10 — переосмыслен по аналогии с колофоном печатного издания.

### 3.1 Header / Navigation
- Логотип DECOSTAR
- Пункты меню: Продукция → Декоры, Производство, Устойчивое развитие, О заводе, Контакты
- Переключатель языка RU/EN/UZ (сегментированный контрол из 3 кнопок)
- Вторичный элемент в шапке: кнопка "Запросить образец" (всегда доступна, sticky header)

### 3.2 Hero
- **Макет:** асимметричный (НЕ центрированный шаблон) — крупный текстовый блок слева, справа — визуальная сборка сигнатурного элемента "Слоёный пресс"; регистрационная метка `+ REGISTRATION 01` в верхнем левом углу вместо generic eyebrow
- **Контент:**
  - Заголовок (5-12 слов), например тональность: "Декоративная бумага для ламината, которой доверяют производители ДСП и МДФ"
  - Подзаголовок: 1-2 предложения о позиционировании (мощность, качество печати, скорость поставки)
  - Primary CTA: "Запросить образец"
  - Secondary CTA: "Смотреть декоры" (якорь на раздел 3.3)
- **Визуал (сигнатурная анимация):** слои — текстурный крафт-лист → печатный декор → глянцевый overlay — сходятся и накладываются друг на друга за ~1.2s при загрузке, оставляя финальную "плиту" как визуал рядом с заголовком. Плейсхолдер-текстуры до получения реальных фото производства.

### 3.3 Продукция / Коллекции декоров (ключевой раздел, отличает от generic-лендинга)
- **Макет:** сетка карточек декоров с фильтром по категории
- **Категории (плейсхолдер-структура):**
  - Древесные текстуры (wood grain)
  - Камень / бетон (stone / concrete)
  - Текстиль / абстракция (fantasy)
  - Унипалитра (unicolors)
- **Карточка декора:** превью-изображение, код декора в mono-шрифте (например `WD-114`), hover-эффект — приподнимается уголок карточки, показывая слой текстуры под ним (тот же сигнатурный мотив "Слоёный пресс", не отдельный zoom-эффект)
- **CTA раздела:** "Скачать каталог декоров (PDF)" — вторичный, не основной приоритет, но нужен как опция для покупателя, изучающего каталог самостоятельно
- Данные по декорам — плейсхолдер-объекты (id, название, категория, изображение), т.к. реального каталога пока нет; структура данных должна легко расширяться

### 3.4 Производственный процесс
- **Макет:** pinned scroll-driven блок; тот же слоёный стек из Hero проходит стадии по мере скролла, прогресс = высота собранной стопки. Нумерация стадий (01-05, mono-шрифт) — легитимна, т.к. это реальная последовательность
- **Этапы (из research §1.2):** Сырьё → Дизайн и цветоделение → Печать (ротогравюра) → Пропитка смолами → Сушка → Прессование на ДСП/МДФ → Контроль качества → Упаковка и логистика
- **Motion:** GSAP ScrollTrigger с пинингом секции, прогресс-индикатор этапов встроен в сам слоёный стек (не отдельный UI-элемент), переход между этапами через fade/transform при скролле
- Fallback без JS/при `prefers-reduced-motion`: обычный вертикальный список этапов с иконками, без пиннинга

### 3.5 Преимущества завода
- **Макет:** сетка 2-3 колонки (как в исходном ТЗ), но с производственно-специфичными пунктами вместо generic:
  1. Собственное производство полного цикла
  2. Широкая линейка декоров и возможность кастомизации под заказчика
  3. Контроль качества на каждом этапе (лаборатория)
  4. Скорость поставки / логистика
  5. Соответствие международным стандартам
- Иконка + заголовок + короткое описание на каждый пункт, цвет бренда как акцент
- **Важно:** пункты НЕ нумеруются (01/02/03) — это не последовательность, а параллельный список преимуществ; нумерация в дизайн-системе зарезервирована только за реально последовательными разделами (§3.4)

### 3.6 Устойчивое развитие
- Отдельный полноценный блок (не строчка в футере), структура под будущий реальный контент:
  - Происхождение сырья (плейсхолдер под FSC/PEFC, если завод получит/имеет сертификат)
  - Экологичность производства (смолы, отходы, энергопотребление)
  - Ссылка/PDF с политикой устойчивого развития (плейсхолдер)

### 3.7 Сертификаты и технические данные (trust-блок)
- Значки сертификатов (плейсхолдер-слоты: ISO, EPF/EN, др. — уточнить у завода)
- Kinetic-counter цифр компании (стагерится при попадании в viewport): тонн бумаги в год, декоров в каталоге, лет на рынке, стран поставки — **значения плейсхолдер, заменить реальными**

### 3.8 Социальное доказательство
- "Нам доверяют" — логотипы клиентов/партнёров
- Стиль: grayscale 50% прозрачности → цвет при hover (зафиксировано в исходном ТЗ и подтверждено индустрией)
- Плейсхолдер-логотипы до получения реальных партнёров

### 3.9 CTA-секция "Запросить образец"
- Полноширинная секция, фон — цвет бренда `#845036` с текстурой древесины Uludag Mese (`background-image: uludag-mese-bg.jpg`, `background-blend-mode: multiply`) — фактура затемняет/варьирует тон, но не осветляет его, поэтому контраст текста остаётся на уровне плоской заливки
- Форма: Имя, Компания, Email/Телефон, Комментарий (какой декор интересует — опционально, select из категорий 3.3)
- Высокий контраст текста на брендовом фоне (доступность)
- Адаптивна под мобильные

### 3.10 Футер — стилизован как "колофон" печатного издания
- Верхний блок на `--press-black`, mono-шрифт, формат печатного колофона:
  ```
  DECOSTAR DECOR PAPER — REGISTRATION No. 2026
  Плотность … г/м² · Коллекций в каталоге: … · Пропитка: ✓
  Производство: [город] · Экспорт: [регионы]
  ```
  (значения — плейсхолдеры до получения реальных данных)
- Ниже — менее акцентная часть: навигация (дублирует header), контакты, соцсети (плейсхолдер-иконки), переключатель языка, копирайт

## 4. Motion Design — спецификация (пересмотрено по `research/03_design_direction.md`)

### 4.1 Сигнатурная анимация — "Слоёный пресс" (единственный акцентный мотив)
| Место | Поведение |
|---|---|
| Hero (§3.2) | Слои крафт-бумага → декор-печать → overlay сходятся и спрессовываются в плиту, ~1.2s при загрузке |
| Производственный процесс (§3.4) | Тот же стек проходит стадии по мере pinned-скролла, прогресс = высота стопки, GSAP ScrollTrigger + scrub |
| Карточка декора (§3.3) | Hover — уголок карточки приподнимается, показывая слой текстуры под ним |

### 4.2 Тихие фоновые эффекты (не конкурируют с сигнатурой)
| Элемент | Анимация | Параметры |
|---|---|---|
| Секции при скролле | Progressive reveal | fade+translateY 12-24px, 400-600ms, ease-out |
| Логотипы партнёров | Grayscale → color | transition on hover |
| Числа-факты | Kinetic counter | считает от 0 до значения при входе в viewport |
| Регистрационные метки секций | Fade-in crosshair-метки | синхронно с eyebrow-подписью секции |

Никаких дополнительных decorative-переходов между секциями (blinds/mask reveal) — сигнатура из §4.1 уже выполняет роль "запоминающегося момента"; добавление второго яркого приёма размыло бы фокус (принцип "спрессовать смелость в одном месте").

**Обязательные ограничения:**
- Полная поддержка `prefers-reduced-motion: reduce` — отключение/упрощение всех нетривиальных анимаций
- Все скролл-анимации только через `transform`/`opacity` (GPU-composited)
- GSAP подключается асинхронно, не блокирует LCP
- Целевой LCP < 2.5s, оптимизированные изображения (WebP/AVIF)

## 5. Контентные плейсхолдеры, требующие реальных данных перед запуском

Список того, что явно помечается как placeholder в дизайне/коде и должно быть заменено:
1. Изображения/названия декоров (раздел 3.3)
2. Фото производства для Hero и раздела 3.4
3. Логотипы сертификатов (раздел 3.7)
4. Цифры компании (тонн/год, лет на рынке, стран поставки) (раздел 3.7)
5. Логотипы клиентов/партнёров (раздел 3.8)
6. Ссылки на соцсети (Instagram/Telegram/LinkedIn пока ведут на `#`) (раздел 3.10)
7. PDF каталога декоров и политики устойчивого развития
8. UZ-перевод всего контента — сделан без носителя языка, требует вычитки перед реальным запуском

> Контакты и география (раздел 3.10) уже реальные: производство — Ташкент, Узбекистан; экспорт — регионы Узбекистана и соседние страны; телефон +998 99 000 00 00. Email `sales@decostar-decor.example` остаётся плейсхолдером до выдачи реального адреса.

## 6. Нефункциональные требования

- Адаптивность: мобильные, планшет, десктоп
- Доступность: семантический HTML, контраст WCAG AA, `prefers-reduced-motion`
- Производительность: Core Web Vitals (LCP < 2.5s), ленивая загрузка изображений вне первого экрана
- SEO: базовая мета-разметка на RU/EN/UZ, семантические заголовки h1-h2-h3
- Трилингвальность: переключатель RU/EN/UZ, весь текстовый контент дублируется во всех трёх версиях. UZ-перевод — черновой (сделан без носителя языка), требует вычитки перед реальным запуском

## 7. Вне скоупа (явно не делаем сейчас)
- Личный кабинет / логин для партнёров (есть у Schattdecor, но избыточно для текущего масштаба)
- Полноценный интерактивный 3D-конфигуратор декора (заменяем на 2D hover-zoom карточки — дешевле в реализации, сопоставимый эффект для decor paper)
- Impregnated paper / finish foil как отдельные продуктовые линейки (см. §1)
- Многоязычность сверх RU/EN/UZ

## 8. Следующие шаги
1. Детальный визуальный дизайн макетов по секциям 3.1-3.10 на основе дизайн-системы §3.0 и `research/03_design_direction.md`
2. Структура кода: разметка секций в `index.html`, стили в `style.css` (CSS-переменные из §3.0), логика (фильтры декоров, kinetic counters, GSAP ScrollTrigger для "Слоёного пресса") в `script.js`
3. Сбор реальных контентных материалов у завода по списку §5 (не блокирует дизайн/вёрстку — идём с плейсхолдерами)
